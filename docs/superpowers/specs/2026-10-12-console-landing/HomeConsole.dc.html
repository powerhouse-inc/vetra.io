Everything is one command away

studio.new

A private studio in seconds

Claimed from a warm pool. Hibernates when idle, wakes when you return.

env.create

Environments with a name

Instant subdomain, or point your own domain with two DNS records.

pkg.install

A registry built in

Publish from Studio, install on any environment, roll forward or back.

git push

Deploy from your repo

A GitHub Action publishes and rolls out on every merge.

db.explore

See your data

Browse the database, logs and metrics without leaving the console.

env.export

Leave with everything

Backups and packages are yours. Restore them on any self-hosted Powerhouse setup.

// for teams who prefer code

Studio is optional. Your repo is the source of truth.

Clone what Studio wrote, keep editing in your IDE, and let the action ship it.

.github/workflows/deploy.yml
on: push
jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: powerhouse-inc/vetra-deploy-action@[TAG]
        with:
          environment: acme-ops
